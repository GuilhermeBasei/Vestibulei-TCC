#Vestibulei-TCC

O Vestibulei é um software desenvolvido como projeto de TCC com o objetivo de auxiliar estudantes na preparação para o ENEM, permitindo a geração de cronogramas de estudos de forma organizada e personalizada.

A proposta do projeto é facilitar o planejamento da rotina de estudos, distribuindo os conteúdos do exame ao longo do período disponível para preparação.
